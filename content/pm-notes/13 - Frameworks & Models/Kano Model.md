# Kano Model

## Definition
Developed by Noriaki Kano in 1984, the Kano Model is a theory for product development and customer satisfaction which classifies customer preferences into five categories: Must-be, One-dimensional, Attractive, Indifferent, and Reverse. It helps PMs understand which features will truly delight users versus those that are simply expected.

## How to Apply It
1. Categorize Features: Use user surveys to classify features into Kano categories.
2. Prioritize the Mix: A healthy roadmap needs all Must-be's, some One-dimensional (to compete on performance), and at least one Attractive (to differentiate).
3. Monitor Decay: Regularly re-evaluate features to see if yesterday's delighter is today's expectation.
